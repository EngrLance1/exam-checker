The sheet is the whole trick

SagotScan reads one specific printed sheet. Because it is always the same, the same blank sheet works for every test. Only your answer key changes.

  1. Four black corner squares. They tell SagotScan where the sheet is, so a tilted or sideways photo still works. All four must be in the picture.
  2. Class number and test set. Students write the number in the boxes and shade the matching circles. The set is A to D.
  3. Shade the circle completely. One circle per item, with a pencil or dark pen. A check, a cross or half a circle does not count.
  4. Items numbered down each column. 10 per column on the 30 and 50-item sheets, 12 on the 60-item sheet.
Print the answer sheet

Prints on A4 or Letter at 100%. Photos work best flat and in good light.

What to know before you start

  • Only the SagotScan sheets are supported. It reads the 30, 50 and 60-item designs above. A different sheet layout will not read correctly.
  • Your work is kept in this browser. Photos are not stored. Use Save test file to keep a copy, because clearing your browser data erases the rest.
  • It is new. It has been tested on generated sheets under tilted, dim and blurry conditions, and on a sample sheet, but not yet on many real classroom photos. Check the first few scans against the paper.
  • Flagged items need your eyes. Double marks, faint marks and possible erasures are highlighted so you can decide.

Questions

Is it free?

Yes. There is nothing to buy and nothing to sign up for.

Where do my students’ photos go?

Nowhere. SagotScan reads each photo in your browser. It has no server and loads nothing from other sites, so nothing is uploaded.

Does it work without internet?

SagotScan has no server, so scoring and item analysis run in your browser. Once the page is open, losing your connection will not stop it. If you reload with no connection, the page itself will not load.

Do I need an account or to install anything?

No. Open the page in Chrome, Edge, Firefox or Safari on a phone or a computer.

Can I use my own answer sheet?

Not yet. SagotScan reads the 30, 50 and 60-item sheets on this page. Print them from the answer sheet page.

My test has 40 items.

Use the 50-item sheet and set the test to 40 items. Items after 40 are ignored.

I teach several classes.

Give each class a section name. You get the MPS per section and for all of them together, and the item analysis can be shown for one section at a time.

Can I get the results into Excel?

Yes. You get an Excel file with scores, MPS, every answer, the item analysis and notes on anything flagged. There is also a printable report.

What if the key was wrong?

Fix it after scoring: accept another letter, change the key, credit everyone, or drop the item. Everything recomputes.

Is the code open?

You can read it on GitHub. No licence has been chosen yet, so it is free to use but not yet free to reuse.
